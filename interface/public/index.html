Rodar como ambiente Docker

Use Docker quando quiser que o PI Studio seja o ambiente de trabalho e cada pasta montada vire um projeto.

cd interface
PI_WORKSPACES_DIR="$HOME" docker compose up --build

O compose monta seus projetos em /workspaces e seu ~/.pi/agent dentro do container para manter agentes, skills, auth e histórico.
