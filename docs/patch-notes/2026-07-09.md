# Patch Notes — 2026-07-09

## Resumo

A infraestrutura de subagentes do PI foi modernizada para roteamento explícito por modelo/esforço, prompts mais compactos, orquestração adaptativa, planejamento executável mais seguro e retomada de Flow baseada no estado remoto do GitHub.

## Destaques

### Agentes, modelos e identidade de runtime

- Frota expandida de 27 para 32 agentes.
- Migração dos papéis principais para as famílias GPT-5.6 Sol, Terra e Luna, com `thinking` explícito.
- `display_name`, `model` e `thinking` agora expõem uma identidade de runtime coerente.
- Novo `builder-design` como tier padrão para frontend/UI e `builder-heavy-design` como escalonamento visual avançado.
- `builder` passou a ser o executor geral de risco normal; `builder-heavy` permanece focado em correção e integração de maior risco.
- Prompts de 26 agentes não-Home foram otimizados de 4.657 para 2.545 linhas (-45,4%), preservando contratos, segurança e compatibilidade de saída.

### Isolamento do Home Preview

- MiniMax M3 e GLM-5.2 ficaram restritos aos agentes Home Preview.
- Adicionados:
  - `seo-content-writer-home`;
  - `website-polisher-home`;
  - `validator-home`.
- O fluxo Home agora usa exclusivamente variantes `*-home` para conteúdo, polish e validação.
- Os seis agentes Home foram preservados byte a byte contra o baseline capturado antes da otimização dos prompts gerais.

### Scouts e Validator

- `scout` e `scout-highspeed` ficaram tecnicamente read-only: somente `read`, `grep`, `find` e `ls`.
- `scout` recebeu limite explícito de 25 turnos.
- O validator geral agora resolve primeiro o alvo nomeado, evita fallback implícito para o repositório inteiro e trata achados fora do escopo como advisories.
- Código vendorizado ou gerado só bloqueia quando relevância e reachability para o alvo são demonstradas.
- Artefatos `.pi/validate/*` deixaram de ser efeito colateral padrão e exigem autorização explícita.

### Orquestração adaptativa

- `SYSTEM.md` foi reescrito em três níveis:
  1. Direct Orchestrator;
  2. Focused Subagents;
  3. Planned Delivery.
- O nível de coordenação agora cresce com risco, dependências, compartilhamento de arquivos e horizonte da tarefa.
- Planner e Builder Skills passaram a reconhecer `builder-design` e validators seletivos como gates independentes.
- Tasks de planner usam contratos compactos com Goal, Change, Acceptance, Validation e Checkpoint, sem duplicar TODO/TILL-DO ou boilerplate operacional.

### `/plan-heavy`

- Validação compatível com tasks compactas e legadas.
- Normalização de paths e bloqueio de alvos absolutos, traversal, glob e paths operacionais inseguros.
- Consistência obrigatória entre `SCHEDULE.md`, nome do arquivo, agente declarado e targets da task.
- Sobreposição de arquivos compartilhados exige dependência serial explícita e não pode ocorrer no mesmo grupo paralelo.
- Validators review-only usam `PASS | BLOCKED` e não geram commits vazios.
- Envelopes carregam estado runtime, recovery, constraints/anchors e sinais de acceptance sem inflar as tasks.
- Adicionado smoke test Node e workflow GitHub Actions para o harness.

### Flow remoto-first

- GitHub tornou-se a autoridade: Project Status → issues/PRs/branches remotas → `.pi/flow` → `.pi/memory`/chat.
- Todo continue/chat novo reconstrói o board com paginação, discovery de Project v2 e inventário de branches remotas.
- Claim determinístico combina assignee, branch `flow/#N-slug` e verificação de SHA.
- WIP padrão limitado a uma issue por executor.
- Transições `in progress`, `in review` e `done` exigem releitura de pós-condição.
- `done` exige PR correspondente com `mergedAt != null`; issue fechada ou PR fechado sem merge vira blocker/anomalia.
- `.pi/flow/<repo>/STATE.md` e `ISSUES.md` são caches reconstruíveis, não locks nem fontes de verdade.
- Project Memory foi alinhado para nunca substituir ou recriar estado remoto do Flow.

### Configuração e instalação

- Modelo padrão alterado para `openai-codex/gpt-5.6-sol`.
- Adicionado `config/models.json` com GPT-5.6 Sol/Terra/Luna e overrides de contexto.
- Context windows configurados em 350k para GPT-5.6 e 585k para os modelos Anthropic.
- Instaladores Unix e PowerShell agora copiam `models.json`, `subagents.json` e temas versionados, além de instalar os providers Alibaba e XAI OAuth.
- `maxConcurrent: 8` passou a ser uma configuração compartilhada para subagentes.
- Cyberpsycho agora é o tema padrão, é instalado em `themes/cyberpsycho.json` e usa escarlate luminoso para `thinkingXhigh`.
- README atualizado com a nova frota, roteamento, pipelines e matriz de modelos.
