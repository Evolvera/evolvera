# OpenGateway

OpenGateway is available in Pi 1.4+ as the **OpenGateway** provider. Use `/login`, choose OpenGateway, and enter your OpenGateway API key. Pi stores that key with its normal provider credentials; use the intended account/profile when logging in. No OAuth flow is claimed or implemented.

The extension discovers models from the `/v1/models` catalog and keeps only models advertising a supported text chat endpoint: Anthropic Messages, [OI] Responses, or [OI] Chat Completions. The catalog request carries the stored API key, because an authenticated catalog is scoped to the models that key may actually call while the public catalog lists every model the gateway serves. Advertising the public list would offer models that answer HTTP 401 `model_access_denied` at inference time, which reads as an expired credential. A key without model entitlement therefore yields a short catalog instead of a long unusable one. Image inputs are supported when advertised; image generation and other non-chat operations are not exposed. Model identifiers are passed through unchanged. Pi's configured output cap is at most 8,192 tokens. Catalog prices are provider estimates converted from per-token USD to Pi's per-million cost units; cache-write cost is estimated using the prompt price. These estimates are not a promise of final charges, and provider discounts can vary by dispatch time. Requests may incur real charges. `openai/o4-mini` is marked as reasoning-capable from its verified catalog identity; unknown models use a conservative reasoning-disabled setting, which is not a claim that the upstream model lacks reasoning.

If the public catalog is unavailable before discovery, Pi retains an OpenAI Responses fallback for `openai/o4-mini`; catalog refresh uses a 10-second timeout and honors cancellation. After successful discovery, Pi's native model-store cache is restored first and retained if a later refresh fails. The fallback's known public pricing metadata is an estimate, not free usage. The extension sends the credential only to the gateway's own catalog endpoint and does not send local user/session analytics identifiers.

OpenGateway API key documentation: <https://opengateway.ai/docs/coding-agents/pi>, <https://opengateway.ai/api-docs>, and <https://opengateway.ai/docs/reference/guides/authentication>.
