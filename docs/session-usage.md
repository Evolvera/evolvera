# `/usage`

`/usage` reports assistant-message token usage for the **current session branch**, grouped by provider and model. It reads the active branch on each invocation, so branch navigation and model changes are reflected without a persisted counter.

In the managed application runtime, `/usage` also requests subscription quota for the selected PI account when invoked. It supports stored Claude (`anthropic`) and OpenAI Codex (`openai-codex`) OAuth credentials only. It shows the selected PI account id, provider window duration, percent used and remaining, reset time in UTC, and fetch time. Window lengths come from the provider response for Codex; Claude's response fields represent its five-hour and seven-day windows. Missing, expired, unsupported, invalid, timed-out, or rejected credentials/requests are shown as unavailable, never as zero. Quotas are independent of local assistant transcript entries.

These are undocumented/private provider HTTP routes, not public API guarantees. Requests are read-only GETs, use a five-second timeout, do not follow redirects or retry, and never refresh credentials. Successful data is cached only in memory for up to five minutes within that selected runtime instance; errors are not cached. No provider response, token, email, or workspace identifier is logged or displayed. Managed quota collection reads only the explicitly selected account's credential store on `/usage`; metadata startup is inert and no global account scan or profile/entitlement lookup occurs. The default/unmanaged extension remains local-only and truthfully reports **“Cotas dos provedores: não consultadas”**.

The local section shows input, output, cache-read, cache-write, and total tokens, plus SDK-reported estimated cost components and total. Cache token categories are summed once alongside input/output, matching the SDK usage totals convention. Costs are values recorded in session usage data, not a provider account balance, invoice, or guarantee of final charges.

The activity calendar is titled **“Atividade desta branch — não é histórico global”** and counts assistant responses by their session-entry timestamps; it does not count real HTTP requests. It is anchored to the current UTC week, displays the last 53 weeks when the terminal width permits (or a labeled shorter recent window when narrow), and shows the UTC date range, month markers, dated-response total, and how many fall inside that window. Older dated responses remain in the branch total but are not placed in the displayed window. Missing, malformed, and future timestamps are excluded and reported as undated; if no valid response timestamps exist, the panel says no dated assistant responses are available. Calendar weeks use UTC boundaries.

The command is read-only and reads only the current branch; the managed quota requests above are the sole provider contact. Quota reports are not verified against real account data here. Neither quota nor local usage is persisted. RPC and print modes retain the plain-text notification/message output; if the TUI custom component API is unavailable, TUI falls back to a plain notification. Native `/session` remains unchanged.
